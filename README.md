# LongShot

A Manifest V3 Chrome extension that captures razor-sharp full-page screenshots, stitched seamlessly and optimized for Google Docs.

- **Extension source & full documentation:** [`longshot/README.md`](longshot/README.md)
- **Install:** `chrome://extensions` → enable Developer mode → **Load unpacked** → select the `longshot` folder.
- **Tests & tooling:** [`dev/`](dev) — `cd dev && npm install && npm test`
